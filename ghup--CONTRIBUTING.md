# Contributing

Two ways to help, both welcome:

1. **Suggest a topic.** Open an issue with the production AI problem you
   are stuck on. Reader topics feed the Layer by Layer newsletter, and
   the best ones become projects in this repo.
2. **Improve a project.** Keep it small and readable: one idea per
   project, plain language comments, and a sample `output.txt` that
   still matches what the code actually prints. If your change alters
   the output, regenerate `output.txt` in the same pull request.

Style rules: 100 to 300 lines of Python per project, no API key required
unless the concept truly demands one, and comments written for a smart
beginner, not for a compiler.
